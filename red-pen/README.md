# Red Pen

A single-page site: a pen drawing is the fixed background, and clicking or touching draws on it with a red pen.

- The pen is always red, with a pencil-like grain, and its line is the same thickness as the black lines in the drawing.
- There's no zooming or scrolling.
- Always dark: the drawing sits on pure black with a thin edge, sized like a photo in a phone viewer.
- It works with a mouse, touch (including several fingers at once) and a stylus, on desktop and on phones.

It's plain static HTML, CSS and JS, so it can be served from any static host (for example GitHub Pages: Settings → Pages → deploy from `main`).
